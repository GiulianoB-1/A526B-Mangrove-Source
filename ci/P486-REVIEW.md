## TX

TG ties are stable insertion order, not guaranteed by type rank. P485 trace confirms REQ before MIXER on start, not TG stop. P486 explicitly selects ADC teardown -> REQ cleanup -> datapath disable, disconnect before bank commit, consistent with donor 5.4 disconnect-before-disable. Actual TG stop trace and multi-path interleaving not supplied; cannot claim exact observed TG stop equivalence.
Preserve all real types, graph, 27 DT routes, TG actions, ADC2 BCS/MBHC condition and DMIC 250us delay. Local early mixer subseq -1 forces all AMIC ADC setup / DMIC setup before regular AMIC REQ, then actual ADC callbacks enable datapath. Down: actual ADC teardown first, normal AMIC mixer REQ cleanup, early mixer datapath disable. Existing TG return handling unchanged; trace actual rc, including register update values/masks and actual SWR calls. No claims about register bus transaction success from cached/no-change updates. Sequence counter is global monotonic, not reset per stream; caller and op distinguish calls. Trace is not a hardware result. DMIC setup uses original DT rate (zero override); no new clocks or votes. Multi-path order between same-rank widgets and cross-component events still needs hardware evidence.
Cross-component TX DEC mux has moved ahead of WCD ADC setup on 5.10; this patch does not alter Bolero TX DEC timing. Its PRE/POST callbacks program decimator and schedule unmute; full cross-component bus ordering is not established by this codec-local change.
## RX order
TG/5.10 up: mux 6/7, dac 7/8, mixer 8/9, pga 9/10, out_drv/hp 11/12. Down: out_drv/hp 3/4, pga 4/5, mixer 5/6, dac 6/7, mux 9/10. No inversion among these classes. WCD938x RDAC1/2 callbacks (DAC), RX1/2 (mixer), HPHL/R PGA callbacks (PGA) retain relative order both directions, definitions matched in TG and P485. RX macro AIFs moved from rank 9 to 5 up and 2 to 11 down: relative ordering flips against mux/dac/mixer and output driver on down, and against PGA (formerly tied up). Inspected P485 RX AIF declarations: NOPM, no event handlers. This is not proof of whole RX path safety, but no direct AIF event pair to reorder. RX and HPH gain code unchanged; HPH hardware verification pending.
## ADSP
Existing TG APR transport p472_tg_apr_ready_work calls p472_tg_apr_a0b_ready only after genuine GET_STATE. apr_adsp_up sets LOADED only when ready, publishes SND_EVENT_UP then queues P486 card work. Startup check catches already-loaded; paired barriers avoid missed startup/UP race. Worker rechecks LOADED, manual enable, one-shot gate. No 60s poll. No SSR auto-rebind after first registration; existing one-shot behavior retained. Manual card_enable enables or disables auto gate, never bypasses ADSP readiness.
